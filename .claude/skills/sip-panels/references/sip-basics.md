# SIP Basics — Terminology and What to Verify

## Anatomy
- **Skins**: typically 7/16" OSB both faces. Some products use fiber-cement
  or metal skins — different capacities entirely.
- **Core**: EPS (most common, graphite-enhanced "GPS" variants exist),
  XPS, or polyurethane/polyiso (injected — higher R per inch, different
  manufacturers). Core type changes R-value, fire behavior, and price.
- **Splines** (panel-to-panel joints): dimensional lumber spline, engineered
  "surface splines" (thin OSB strips in routed slots), block splines
  (mini-SIP), or I-joist splines for roofs. Structural behavior differs —
  the manufacturer's details govern.
- **Plates**: bottom/top plates field-installed from dimensional lumber.
- **Chases**: factory-routed vertical/horizontal electrical raceways.

## Common thicknesses
Walls commonly 4.5" and 6.5" nominal; roofs 8.25"–12.25". Actual offerings
and R-values vary by manufacturer and core — take them from the current
product data sheet, not from this file.

## What to verify in a manufacturer's ESR / code report
1. Report is CURRENT (ESRs expire and get revised — check date)
2. Covered products match the quoted panel (skin, core, thickness)
3. Allowable axial load table + conditions (height, eccentricity)
4. Allowable transverse load (wind) table for the wall height in play
5. Racking/shear wall values and required fastening
6. Header capability over openings (many SIPs need inserted headers —
   lumber or LVL within the panel; who engineers those?)
7. Fire assembly listings if a rated assembly is needed
8. Limitations section — seismic category, wind speed caps, story limits

## Estimating rules of thumb (process, not prices)
- Freight is a real line item: panels cube out trucks; get delivered price.
- Crane: typically 1–2 days for a simple house shell; get the erector's
  number, don't guess.
- Waste factor is LOW (factory-cut) — that's part of the value story; but
  field-modification costs are HIGH. Accuracy of openings on plans matters
  more than with stick framing.
- Compare against stick-framing bids on a whole-assembly basis: SIP price
  includes sheathing + insulation + framing labor equivalents. Add back
  the electrician's chase-related savings and the shorter dry-in time
  (carrying-cost savings) to be fair to the SIP number.
