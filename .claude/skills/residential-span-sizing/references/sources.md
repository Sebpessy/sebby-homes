# Authoritative Source Map — Residential Wood Framing

Purpose: when a sizing question needs a real capacity/span value, this file
tells you WHICH document to ask the user for (or to fetch, if the session's
network allows). Table numbers below are locators to help find the right
page — always confirm the table title matches the question once the
document is open, since numbering shifts between IRC editions.

## The rule, restated
Read values only from an open document in the session. Cite document +
table + cell. If the document isn't available, output demand-side numbers
and name the source below; do not fill the gap from memory.

## Other authoritative documents
- **AWC DCA 6** — Prescriptive Residential Wood Deck Construction Guide
  (free from awc.org). Best single deck reference; aligned to a specific
  IRC edition noted on its cover.
- **AWC Span Tables for Joists and Rafters / NDS Supplement** — lumber
  design values (Fb, Fv, E) by species/grade/size. SYP values are set by
  SPIB and were substantially revised in 2013 — reject any pre-2013 SYP
  table the user surfaces.
- **Southern Forest Products Association (southernpine.com)** — SYP-specific
  span tables and headers/beams guides.
- **Engineered lumber**: only the manufacturer's current documents count —
  e.g., Weyerhaeuser TJ specifier's guides (Microllam LVL, Parallam PSL,
  TJI joists), Boise Cascade specifier guides, plus the product's ICC-ES
  ESR number. Supplier reps provide free project-specific sizing runs
  (ForteWEB etc.) — recommend this route for any multi-ply LVL beam.
